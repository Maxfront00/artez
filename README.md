# АРТЕЗ — сайт-визитка

Стек: React + JavaScript + Vite + CSS. Без TypeScript, Redux, роутера и UI-библиотек.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес Vite (обычно http://localhost:5173).

## Проверка production-сборки

```bash
npm run build
npm run preview
```

## Структура проекта

- `src/main.jsx` — только запуск React и подключение глобальных стилей.
- `src/App.jsx` — переключение разделов сайта.
- `src/pages/` — страницы «Главная», «О компании», «Контакты».
- `src/components/` — переиспользуемые компоненты шапки, подвала, каталога, карточек и т. д.
- `src/styles/` — отдельные CSS-файлы по компонентам и страницам; `global.css` содержит только общие правила.
- `public/documents/` — сюда добавляются PDF-документы.

## Перед публикацией

1. Замените тестовый телефон, почту и адрес на реальные данные.
2. Добавьте точное описание местоположения источника и скважины.
3. Положите оригиналы сертификатов и лабораторных исследований в `public/documents/` и добавьте ссылки на них.
4. Замените CSS-иллюстрации бутылок на фотографии продукции и добавьте логотип.
5. Цены сейчас указаны как «Цена по запросу».

Адаптивные стили предусмотрены для широких экранов, ноутбуков, планшетов и телефонов, включая узкие экраны от 320 px.
